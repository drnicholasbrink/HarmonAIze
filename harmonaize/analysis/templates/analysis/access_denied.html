Analysis access required

You need project ownership or manager access before this workspace is available.

Why access is blocked

The Analysis workspace is restricted to project owners, project managers, analysis administrators, and platform superusers. Permissions are synced to Armadillo to keep project access consistent.

What happens once granted

  • Your project and users are synced to Armadillo.
  • Target-study long-format Parquet datasets are generated and uploaded.
  • Project-level analysis workflows become available.

R and ROCK context

ROCK services are consumed by Armadillo during analysis execution. Access control is still governed by HarmonAIze project membership and Armadillo project permissions.
